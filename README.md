# ♠️ Poker Club at OSU

A web platform for the Oregon State University Poker Club.

This project gives club members a central place to learn about the club, access member tools, and create temporary shared browser rooms powered by [Neko](https://neko.m1k1o.net/) and [neko-rooms](https://github.com/m1k1o/neko-rooms).

The main feature is a GTO Wizard room dashboard where members can spin up virtual sessions for poker study tools, strategy resources, and group review.

---

## ✨ Features

- Club Website
- GTO Wizard Rooms using Neko Rooms
- Terraform Infrastructure Scripts

---

## 🧱 Tech Stack

### Frontend

- [Next.js](https://nextjs.org/)

- Tailwind CSS

- [Neko](https://neko.m1k1o.net/)
